# Titanic 乘客生存预测项目

## 📌 项目简介
本项目基于 Kaggle 经典泰坦尼克号数据集，完成**完整二分类机器学习建模流程**。通过数据清洗、多方案特征选择对比、XGBoost 超参搜索、模型拟合诊断与模型保存，实现对乘客是否生还的精准预测。

本项目区别于普通入门 Demo，严格遵循**机器学习工程化流程**，杜绝数据泄露，可作为机器学习入门实战标准项目。

## 📊 项目流程
1. **数据预处理**
- 剔除无意义字段：乘客ID、姓名、船舱、票号
- 数值特征：中位数填充缺失值
- 无序类别特征：OneHot 编码
- 有序类别特征：序数编码
- 使用 Pipeline + ColumnTransformer 模块化处理，避免数据泄露

2. **数据集划分**
- 训练集 80%、测试集 20%
- 分层抽样 stratify，保证正负样本比例一致

3. **多方案特征选择对比实验**
- 方差筛选 VarianceThreshold
- 单变量特征筛选 GenericUnivariateSelect
- 模型自动特征筛选 SelectFromModel
- 递归特征消除 RFE

✅ 最终实验结论：**VarianceThreshold 方差筛选效果最优**

4. **模型超参优化**
- 使用 RandomizedSearchCV 随机搜索，高效大范围寻优
- 对 XGBoost 学习率、树深度、迭代次数、采样率、正则系数进行精细化调参
- 5折交叉验证保证模型泛化能力

5. **模型拟合诊断**
- 绘制学习曲线判断拟合状态
- 模型存在**轻微过拟合**，为小数据集正常现象
- 验证曲线持续上升，说明模型仍有提升空间

6. **模型持久化保存**
- 保存完整 Pipeline（预处理 + 特征筛选 + 最优XGB模型）
- 后续可直接加载用于预测，无需重复训练

## 🏆 实验结果
- 最优模型：XGBoost（基于方差特征筛选）
- 5折交叉验证 AUC：0.8147
- 模型状态：轻微过拟合，泛化性能良好
- 特征工程结论：低方差噪声特征剔除后，模型稳定性明显提升

## 🧰 技术栈
- **数据处理**：Pandas、SKlearn Pipeline、ColumnTransformer
- **特征工程**：缺失值填充、OneHot、Ordinal、VarianceThreshold、RFE 等多方案对比
- **模型算法**：XGBoost 分类器
- **参数寻优**：RandomizedSearchCV
- **模型诊断**：学习曲线、AUC 评估
- **模型保存**：Joblib
